welcome to the development page of suno wawa pi sewi kalama!

general guidelines

  • respect everyone's work. don't overwrite someone else's translations just because you don't like them and not because they're objectively bad, please discuss it first
  • don't make us make more rules. :D

how to use

  1. get a token from an administrator and log in via the login page
  2. go to the "files" tab and select the relevant file
  3. find the string you want to translate (english and spanish translations are given), then translate it to toki pona and click "save"
  4. once you're done with your batch of edits, go to the exports page and click "build new" to build a .zip containing your and everyone else's edits
  5. download the newly created archive and put it under sd:/atmosphere/contents/0100D9F01D474000/romfs/ (sd:/ is Ryujinx/sdcard if you're using Ryujinx)
  6. launch the game with the language set to Latin American Spanish and test out your translation!

just a visitor? skip to step 5.
